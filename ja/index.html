EyesAwayについて

EyesAwayは、20-20-20ルールを実践しやすくすることで、長時間の画面使用中に定期的な休憩を取ることをサポートします。

20-20-20ルール

画面から目を離して休憩するためのリマインダーを定期的に受け取れます。

カスタマイズ可能

タイマーの時間、サウンド、バイブレーション、通知を好みに合わせて調整できます。

複数言語に対応

自分に合った言語でEyesAwayを使用できます。

プライバシーポリシー

最終更新日： 2026年9月2日

EyesAwayはSamuel Silvaによって開発されています。本プライバシーポリシーでは、このアプリケーションを使用する際にEyesAwayが情報をどのように取り扱うかについて説明します。

1. 収集する情報

EyesAwayでは、ユーザーにアカウントの作成を求めることはなく、氏名、メールアドレス、電話番号、連絡先、写真、マイク録音、その他の個人を特定できる情報を直接提供するよう求めることもありません。

EyesAwayは広告を表示するためにGoogle Mobile Ads SDKを使用します。その動作の一環として、Google Mobile Ads SDKは、IPアドレス、アプリケーションや広告とのユーザーの操作、診断情報やパフォーマンス情報、および該当する場合には広告識別子などの端末またはアカウントの識別子を含む一定の情報を自動的に収集し、共有する場合があります。

Googleは、これらの情報が広告、分析、不正防止などの目的で使用される場合があるとしています。

EyesAwayは、独自のユーザーアカウントシステムや、これらの広告データを保存する開発者運営のデータベースを運営していません。

2. 端末内に保存される情報

EyesAwayは、機能を提供し設定を記憶するために、一部の情報を端末内に保存します。

  • 画面使用時間と休憩時間の長さ；
  • 現在のタイマー状態と残り時間；
  • 選択した言語；
  • サウンド設定と選択した通知音；
  • バイブレーション設定；
  • 通知設定；
  • アプリケーションの初期設定およびウェルカム画面の設定。

これらの情報は、アプリケーションの動作と設定のためにのみ使用されます。

EyesAwayは、端末内に保存されたこれらの情報を開発者に送信しません。

3. アプリの権限

EyesAwayは、以下のAndroid権限を要求または使用する場合があります。

  • 通知： タイマー通知を表示し、画面使用時間または休憩時間が終了したときにお知らせするために使用します。
  • 正確なアラーム： 端末がアイドル状態の場合やアプリケーションが開かれていない場合を含め、画面使用時間と休憩時間の各フェーズの切り替えを正確な時刻にスケジュールするために使用します。正確なアラームへのアクセスはタイマー機能のためにのみ使用され、ユーザーデータの収集や送信には使用されません。
  • Wake lock： 短い休憩時間中に、画面が消灯していてもタイマー処理を有効に保つため、一時的に使用します。
  • バイブレーション： 任意の振動通知を提供するために使用します。
  • フォアグラウンドサービス： アプリケーションが画面に表示されていないときでも、実行中のEyesAwayタイマーを維持するために使用します。
  • インターネット： Googleの広告およびプライバシーメッセージングサービスへのアクセス、広告のリクエストと表示、ならびに広告機能に必要な範囲でこれらのサービスと通信するために使用します。

これらの権限は、対応するアプリケーション機能を提供するためにのみ使用されます。

EyesAwayは、位置情報、カメラ、マイク、連絡先、写真、その他の個人的なコンテンツへのアクセスを要求しません。

4. インターネットアクセス

EyesAwayは、Googleの広告およびプライバシーメッセージングサービスにアクセスし、広告をリクエストおよび表示するためにインターネット接続を使用します。

アプリケーションの主要なタイマー機能にはインターネット接続は必要ありません。タイマー設定、時間、サウンド、バイブレーション設定、その他のEyesAway設定データは引き続き端末内で処理されます。

EyesAwayに含まれるサウンドや音声案内はアプリケーション内に保存され、端末上でローカルに再生されます。ユーザーの音声が録音されたり、外部サービスに送信されたりすることはありません。

Androidのバックアップサービスまたは端末移行サービスは、以下のセクションで説明するように、端末内に保存されたアプリケーションデータを独立して処理する場合があります。

5. Androidバックアップと端末移行

EyesAwayは、設定とタイマー情報を端末内に保存します。

Android端末、アカウント、およびバックアップ設定によっては、端末内に保存された一部のアプリケーションデータが、Androidオペレーティングシステムまたはユーザーのバックアッププロバイダーが提供するバックアップや端末移行の仕組みに含まれる場合があります。

これらのバックアップおよび復元処理は、オペレーティングシステムまたはバックアッププロバイダーによって管理されており、EyesAwayの開発者が運営したりアクセスしたりするものではありません。

6. 情報の共有

EyesAwayの開発者は、ユーザーから直接提供された個人情報を販売または貸与しません。

EyesAwayはGoogle Mobile Ads SDKを使用します。広告サービスの提供にあたり、GoogleおよびGoogle Mobile Adsに関連する広告サービスは、本プライバシーポリシーおよびGoogleの適用されるプライバシー文書に記載されているとおり、一定の情報を収集、処理、共有する場合があります。

これには、IPアドレス、アプリケーションや広告との操作、診断情報、および該当する場合には端末またはアカウントの識別子が含まれることがあります。

広告データは、適用されるプライバシーポリシーおよびユーザーのプライバシー設定に従ってGoogleおよびそのサービスによって処理されます。

7. データのセキュリティ

EyesAwayは、アプリケーション設定とタイマー情報をユーザーの端末内に保存することで、データの取り扱いを最小限に抑えるよう設計されています。

現在のバージョンでは、個人データまたは機微なユーザーデータを開発者が運営するサーバーに送信しません。

端末内に保存されたアプリケーションデータには、Androidオペレーティングシステムおよびユーザー端末が提供するセキュリティ機構が適用されます。

Google Mobile Ads SDKを介して送信される情報はGoogleによって処理されます。Googleは、Google Mobile Ads SDKが収集したデータはTransport Layer Security（TLS）を使用して通信中に暗号化されるとしています。

8. データの保持と削除

EyesAwayは、ローカルに保存された設定とタイマー情報がユーザーの端末上でアプリケーションに保存されている限り、それらを保持します。

ユーザーは、Androidの設定からアプリケーションのストレージを消去するか、アプリケーションをアンインストールすることで、端末内に保存されたEyesAwayのデータを削除できます。

Androidまたはアカウントベースのバックアップに含まれている可能性のあるデータには、該当するオペレーティングシステムまたはバックアッププロバイダーの保持および削除に関する管理が適用されます。

EyesAwayはユーザーアカウントや開発者運営のユーザーデータベースを保持していないため、削除すべき別個のアカウントやサーバー側のユーザーデータはありません。

Googleの広告およびプライバシーサービスによって処理される情報には、Google独自の保持、削除、プライバシーに関する方針が適用されます。EyesAwayはGoogle Mobile Adsが使用するサーバーを運営しておらず、Googleが広告サービスの一環として保持するデータを直接削除することはできません。

9. 第三者サービス

EyesAwayは以下のGoogleサービスを統合しています：

Google Mobile Ads SDK（AdMob）： 広告をリクエストして表示するために使用します。SDKは、広告、分析、不正防止などの目的で、IPアドレス、ユーザーの操作、診断情報、端末またはアカウントの識別子などの情報を収集および処理する場合があります。

Google User Messaging Platform（UMP）： 必要な場合にプライバシーおよび同意に関するメッセージを表示し、対象となるユーザーが広告に関するプライバシー設定を管理できるようにするために使用します。

プライバシーまたは同意に関する選択肢の利用可否および種類は、ユーザーに適用される地域やプライバシー要件によって異なる場合があります。

Googleによる情報の処理には、Googleの適用されるプライバシーポリシーおよび利用規約が適用されます。

アプリケーションは、機能を提供するために標準のAndroidおよびAndroidXライブラリを使用しています。

Androidバックアップ、アプリケーション権限、通知などのシステムレベルのサービスは、Androidオペレーティングシステムによって提供および管理されます。

必要な場合、EyesAwayは広告をリクエストする前に、広告に関するプライバシー設定を取得または管理するため、Google User Messaging Platformを使用します。プライバシーオプションへの入口が必要なユーザーは、アプリケーションの設定画面から「プライバシー オプション」を利用できます。

変更はこのページに反映され、「最終更新日」もそれに応じて更新されます。

ユーザーには、本プライバシーポリシーを定期的に確認することを推奨します。
