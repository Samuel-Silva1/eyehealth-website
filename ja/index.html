EyeHealthについて

EyeHealthは、長時間の画面使用中に定期的な休憩を取れるよう、 20-20-20ルールをより簡単に実践できるようサポートします。

20-20-20ルール

定期的に画面から目を離して休憩し、 目を休ませるためのリマインダーを受け取れます。

カスタマイズ可能

タイマーの時間、サウンド、バイブレーション、 通知を好みに合わせて調整できます。

複数の言語に対応

お好みの言語でEyeHealthを使用できます。

プライバシーポリシー

最終更新日： 2026年8月24日

EyeHealthはSamuel Silvaによって開発されています。 このプライバシーポリシーでは、EyeHealthの利用時に 情報がどのように取り扱われるかについて説明します。

1. 収集する情報

EyeHealthでは、ユーザーがアカウントを作成したり、氏名、メールアドレス、 電話番号、連絡先、写真、マイクによる録音、その他の個人を特定できる情報を 直接提供したりする必要はありません。

EyeHealthは、広告を表示するためにGoogle Mobile Ads SDKを使用します。 Google Mobile Ads SDKは、その動作の一環として、IPアドレス、 アプリおよび広告とのユーザーインタラクション、診断・パフォーマンス情報、 ならびに該当する場合は広告識別子などの端末またはアカウントの識別子を含む 一定の情報を自動的に収集し、共有する場合があります。

Googleは、これらの情報が広告、分析、不正行為の防止などの目的に 使用される場合があると説明しています。

EyeHealthは、独自のユーザーアカウントシステムや、 この広告データを含む開発者運営のデータベースを運用していません。

2. 端末内に保存される情報

EyeHealthは、機能を提供し、ユーザーの設定を記憶するために、 一部の情報を端末内に保存します。

  • 画面使用時間と休憩時間の長さ。
  • 現在のタイマーの状態と残り時間。
  • 選択された言語。
  • サウンド設定と選択された通知音。
  • バイブレーション設定。
  • 通知設定。
  • アプリの初期設定およびウェルカム画面の設定。

これらの情報は、アプリの動作および設定のためにのみ使用されます。

EyeHealthは、端末内に保存されたこれらの情報を開発者へ送信しません。

3. アプリの権限

EyeHealthは、以下のAndroid権限を要求または使用する場合があります。

  • 通知： タイマーの通知を表示し、画面使用時間または休憩時間が終了した際に ユーザーへ知らせるために使用されます。
  • 正確なアラーム： 端末がアイドル状態の場合やアプリが実際に開かれていない場合も含め、 画面使用時間と休憩時間の切り替えを正確な時刻に実行するために使用されます。 正確なアラームへのアクセスはタイマー機能のためにのみ使用され、 ユーザーデータの収集や送信には使用されません。
  • Wake lock： 短い休憩時間中、画面がオフになっていてもタイマーの処理を 継続できるよう、一時的に使用されます。
  • バイブレーション： 任意のバイブレーション通知を提供するために使用されます。
  • フォアグラウンドサービス： アプリが画面上に表示されていない場合でも、 EyeHealthのアクティブなタイマーを継続して動作させるために使用されます。
  • インターネット： Googleの広告サービスとプライバシーメッセージサービスへのアクセス、 広告のリクエストと表示、および広告機能に必要なこれらのサービスとの 通信のために使用されます。

これらの権限は、対応するアプリ機能を提供するためにのみ使用されます。

EyeHealthは、位置情報、カメラ、マイク、連絡先、写真、 その他の個人的なコンテンツへのアクセスを要求しません。

4. インターネットアクセス

EyeHealthは、Googleの広告サービスとプライバシーメッセージサービスへの アクセス、および広告のリクエストと表示のためにインターネット接続を使用します。

アプリの中核となるタイマー機能には、インターネット接続は必要ありません。 タイマーの設定、時間、サウンド、バイブレーション設定、 その他のEyeHealthの設定データは、引き続き端末内で処理されます。

EyeHealthに含まれるサウンドおよび音声案内はアプリ内に保存され、 端末上でローカルに再生されます。ユーザーの音声が録音されたり、 外部サービスへ送信されたりすることはありません。

Androidのバックアップまたは端末移行サービスは、 以下のセクションで説明するように、端末内に保存されたアプリデータを 独立して処理する場合があります。

5. Androidのバックアップと端末移行

EyeHealthは、設定およびタイマー情報を端末内に保存します。

Android端末、アカウント、バックアップ設定によっては、 端末内に保存された一部のアプリデータが、 Androidオペレーティングシステムまたはユーザーのバックアップ プロバイダーによるバックアップや端末移行の仕組みに含まれる場合があります。

これらのバックアップおよび復元処理は、 オペレーティングシステムまたはバックアッププロバイダーによって管理され、 EyeHealthの開発者が運用するものではなく、 開発者がそのデータにアクセスすることもありません。

6. 情報の共有

EyeHealthの開発者は、ユーザーが直接提供した個人情報を販売または貸与しません。

EyeHealthはGoogle Mobile Ads SDKを使用します。広告サービスを提供する過程で、 GoogleおよびGoogle Mobile Adsに関連する広告サービスは、 このプライバシーポリシーおよびGoogleの該当するプライバシー関連文書に 記載されている一定の情報を収集、処理、共有する場合があります。

これには、IPアドレス、アプリおよび広告とのインタラクション、診断情報、 ならびに該当する場合は端末またはアカウントの識別子が含まれる場合があります。

広告データは、Googleおよびそのサービスにより、該当するプライバシーポリシーと ユーザーのプライバシーに関する選択に従って取り扱われます。

7. データのセキュリティ

EyeHealthは、アプリの設定およびタイマー情報をユーザーの端末内に 保存することで、データの取り扱いを最小限に抑えるよう設計されています。

現在のバージョンでは、ユーザーの個人データまたは機密性の高いデータを 開発者が運営するサーバーへ送信しません。

端末内に保存されたアプリデータは、Androidオペレーティングシステム およびユーザーの端末が提供するセキュリティ機能によって保護されます。

Google Mobile Ads SDKによって送信される情報はGoogleが取り扱います。 Googleは、Google Mobile Ads SDKが収集するデータについて、 転送時にTransport Layer Security（TLS）を用いて暗号化されると説明しています。

8. データの保持と削除

EyeHealthは、アプリによってユーザーの端末内に保存されている間、 設定およびタイマー情報を保持します。

ユーザーは、Androidの設定からアプリのストレージを消去するか、 アプリをアンインストールすることで、 EyeHealthに保存されたローカルデータを削除できます。

Androidまたはアカウントベースのバックアップに含まれた可能性のある データについては、該当するオペレーティングシステムまたは バックアッププロバイダーの保持および削除に関する管理方法が適用されます。

EyeHealthはユーザーアカウントや開発者が運営するユーザーデータベースを 保持していないため、個別に削除するアカウントデータや サーバー側のユーザーデータはありません。

Googleの広告サービスおよびプライバシーサービスによって処理される情報には、 Google独自の保持、削除、プライバシーに関する取扱いが適用されます。 EyeHealthはGoogle Mobile Adsが使用するサーバーを運営しておらず、 Googleが広告サービスの一環として保持するデータを直接削除することはできません。

9. 第三者サービス

EyeHealthは、以下のGoogleサービスを組み込んでいます。

Google Mobile Ads SDK (AdMob)： 広告のリクエストと表示に使用されます。このSDKは、広告、分析、 不正行為の防止などの目的で、IPアドレス、ユーザーインタラクション、 診断情報、端末またはアカウントの識別子などの情報を収集し、 処理する場合があります。

Google User Messaging Platform (UMP)： 必要な場合にプライバシーおよび同意に関するメッセージを表示し、 対象となるユーザーが広告に関するプライバシー設定を管理できるようにするために使用されます。

利用できるプライバシーまたは同意に関するオプションとその種類は、 ユーザーに適用される地域およびプライバシー要件によって異なる場合があります。

Googleによる情報の処理には、Googleの該当するプライバシーポリシーと規約が適用されます。

本アプリは、機能を提供するために標準のAndroidおよびAndroidX ライブラリを使用しています。

Androidのバックアップ、アプリの権限、通知などのシステムレベルの サービスは、Androidオペレーティングシステムによって提供および管理されます。

必要な場合、EyeHealthは広告をリクエストする前に、Google User Messaging Platformを使用して 広告に関するプライバシー設定を取得または管理します。プライバシーオプションへの アクセスポイントが必要なユーザーは、アプリの設定画面から「Privacy Options」 コントロールにアクセスできます。

EyeHealthの機能またはデータの取り扱い方法が変更された場合、 本プライバシーポリシーを更新することがあります。

変更があった場合はこのページに反映され、 「最終更新日」もそれに応じて更新されます。

ユーザーには、本プライバシーポリシーを定期的に確認することを推奨します。
