隐私政策

最后更新： 2026年9月2日

EyesAway 由 Samuel Silva 开发。本隐私政策说明您使用本应用程序时，EyesAway 如何处理相关信息。

1. 我们收集的信息

EyesAway 不要求用户创建账户，也不要求用户直接提供姓名、电子邮件地址、电话号码、联系人、照片、麦克风录音或其他可识别个人身份的信息。

EyesAway 使用 Google Mobile Ads SDK 展示广告。在运行过程中，Google Mobile Ads SDK 可能会自动收集并共享某些信息，包括 IP 地址、用户与应用程序及广告的互动、诊断和性能信息，以及在适用情况下的设备或账户标识符，例如广告标识符。

Google 表示，这些信息可能用于广告、分析和防欺诈等用途。

EyesAway 不运营自己的用户账户系统，也不运营由开发者管理并存储这些广告数据的数据库。

2. 本地存储的信息

EyesAway 会在您的设备本地存储某些信息，以提供其功能并记住您的偏好设置。

  • 屏幕使用时间和休息时间的时长；
  • 当前计时器状态和剩余时间；
  • 所选语言；
  • 声音偏好和所选通知声音；
  • 振动偏好；
  • 通知偏好；
  • 应用程序设置和欢迎界面偏好。

这些信息仅用于应用程序的运行和配置。

EyesAway 不会将这些本地存储的信息传输给开发者。

3. 应用权限

EyesAway 可能会请求或使用以下 Android 权限。

  • 通知： 用于显示计时器通知，并在屏幕使用时间或休息时间结束时提醒您。
  • 精确闹钟： 用于精确安排屏幕使用阶段与休息阶段之间的切换，包括设备处于空闲状态或应用程序未主动打开时。精确闹钟权限仅用于计时器功能，不用于收集或传输用户数据。
  • 唤醒锁（Wake lock）： 在短暂休息期间临时使用，以便在屏幕关闭时保持计时器处理处于活动状态。
  • 振动： 用于提供可选的振动提醒。
  • 前台服务： 用于在应用程序当前未显示在屏幕上时，使正在运行的 EyesAway 计时器继续运行。
  • 互联网： 用于访问 Google 的广告和隐私消息服务、请求并展示广告，以及根据广告功能需要与这些服务通信。

这些权限仅用于提供相应的应用程序功能。

EyesAway 不会请求访问您的位置、相机、麦克风、联系人、照片或其他个人内容。

4. 互联网访问

EyesAway 使用互联网连接来访问 Google 的广告和隐私消息服务，并请求和展示广告。

应用程序的核心计时器功能不需要互联网连接。计时器设置、时长、声音、振动偏好以及其他 EyesAway 配置数据仍在设备本地处理。

EyesAway 中包含的声音和语音提示存储在应用程序内部，并在设备本地播放。不会录制用户音频，也不会将音频发送到外部服务。

Android 备份或设备转移服务可能会按照下一节所述，独立处理本地存储的应用程序数据。

5. Android 备份与设备转移

EyesAway 会将其设置和计时器信息存储在您的设备本地。

根据您的 Android 设备、账户和备份设置，某些本地存储的应用程序数据可能会被纳入由 Android 操作系统或用户的备份提供商提供的备份或设备转移机制中。

这些备份和恢复过程由操作系统或备份提供商管理，并非由 EyesAway 开发者运营，开发者也无法访问这些过程。

6. 信息共享

EyesAway 开发者不会出售或出租用户直接提供的个人信息。

EyesAway 使用 Google Mobile Ads SDK。在提供广告服务的过程中，Google 以及与 Google Mobile Ads 相关的广告服务可能会按照本隐私政策和 Google 适用的隐私文档所述，收集、处理和共享某些信息。

这可能包括 IP 地址、与应用程序和广告的互动、诊断信息，以及在适用情况下的设备或账户标识符。

广告数据由 Google 及其服务根据其适用的隐私政策和用户的隐私选择进行处理。

7. 数据安全

EyesAway 旨在通过将应用程序设置和计时器信息保存在用户设备本地，尽量减少数据处理。

当前版本不会将个人或敏感用户数据传输到由开发者运营的服务器。

本地存储的应用程序数据受 Android 操作系统和用户设备所提供的安全机制保护。

通过 Google Mobile Ads SDK 传输的信息由 Google 处理。Google 表示，Google Mobile Ads SDK 收集的数据在传输过程中使用传输层安全协议（TLS）进行加密。

8. 数据保留与删除

只要本地存储的设置和计时器信息仍由应用程序保存在用户设备上，EyesAway 就会保留这些信息。

用户可以通过 Android 设置清除应用程序存储空间，或卸载应用程序，从而删除本地存储的 EyesAway 数据。

可能已包含在 Android 备份或基于账户的备份中的数据，受相关操作系统或备份提供商的保留和删除控制约束。

EyesAway 不维护用户账户或由开发者运营的用户数据库，因此不存在需要删除的独立账户或服务器端用户数据。

由 Google 广告和隐私服务处理的信息受 Google 自身的数据保留、删除和隐私惯例约束。EyesAway 不运营 Google Mobile Ads 使用的服务器，也无法直接删除 Google 作为其广告服务一部分而维护的数据。

9. 第三方服务

EyesAway 集成以下 Google 服务：

Google Mobile Ads SDK（AdMob）： 用于请求并展示广告。该 SDK 可能会收集和处理包括 IP 地址、用户互动、诊断信息以及设备或账户标识符在内的信息，用于广告、分析和防欺诈等目的。

Google User Messaging Platform（UMP）： 用于在需要时展示隐私和同意消息，并允许符合条件的用户管理其与广告相关的隐私选择。

隐私或同意选项的可用性和类型可能会因用户所在地区及适用的隐私要求而有所不同。

Google 对信息的处理受其适用的隐私政策和条款约束。

本应用程序使用标准 Android 和 AndroidX 库来提供应用功能。

Android 备份、应用程序权限和通知等系统级服务由 Android 操作系统提供和管理。

在需要时，EyesAway 会在请求广告之前使用 Google User Messaging Platform 获取或管理与广告相关的隐私选择。对于需要提供隐私选项入口的用户，可从应用程序设置界面访问“隐私选项”控件。

10. 本隐私政策的变更

如果 EyesAway 的功能或数据处理方式发生变化，本隐私政策可能会更新。

任何变更都将反映在本页面上，并相应更新“最后更新”日期。

建议用户定期查看本隐私政策。
